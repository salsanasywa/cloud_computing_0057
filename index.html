01 · Dasar

Apa itu Cloud Computing?

Cloud computing atau komputasi awan adalah penyediaan sumber daya komputasi—seperti server, penyimpanan, database, jaringan, dan perangkat lunak—melalui internet sesuai kebutuhan.

🌐

Akses melalui internet

Pengguna dapat mengakses layanan dari berbagai perangkat selama tersedia koneksi dan izin yang sesuai.

📈

Fleksibel dan skalabel

Kapasitas layanan dapat ditambah atau dikurangi mengikuti kebutuhan pengguna atau organisasi.

💳

Bayar sesuai pemakaian

Banyak layanan menggunakan model biaya berdasarkan kapasitas atau sumber daya yang digunakan.

02 · Perkembangan

Sejarah singkat cloud computing

Konsep komputasi awan berkembang dari gagasan berbagi sumber daya komputer hingga layanan komputasi modern yang tersedia melalui internet.

1950–1960-an

Time-sharing dan komputer mainframe

Komputer berukuran besar sangat mahal. Konsep time-sharing memungkinkan banyak pengguna berbagi waktu dan sumber daya satu komputer melalui terminal.

1960-an

Gagasan komputasi sebagai utilitas

John McCarthy pernah menyampaikan gagasan bahwa komputasi suatu saat dapat disediakan seperti layanan utilitas, mirip listrik atau telepon.

1990-an

Internet dan komputasi terdistribusi

Perkembangan internet, jaringan, dan virtualisasi membantu membuka jalan bagi layanan komputasi jarak jauh.

2000-an

Layanan cloud komersial

Penyedia teknologi mulai menawarkan penyimpanan, aplikasi, dan infrastruktur melalui internet dengan model layanan yang lebih mudah digunakan.

2010-an–kini

Cloud menjadi fondasi digital

Cloud digunakan untuk situs web, aplikasi bisnis, analisis data, kecerdasan buatan, Internet of Things, dan berbagai layanan digital.

03 · Model layanan

Tiga model layanan utama

Model layanan cloud dibedakan berdasarkan bagian teknologi yang dikelola oleh penyedia dan bagian yang dikelola pengguna.

🧩

IaaS

Infrastructure as a Service. Menyediakan sumber daya dasar seperti mesin virtual, jaringan, dan penyimpanan. Contoh: Amazon EC2 dan Azure Virtual Machines.

🛠️

PaaS

Platform as a Service. Menyediakan lingkungan untuk membangun dan menjalankan aplikasi tanpa mengelola seluruh server. Contoh: Google App Engine.

📱

SaaS

Software as a Service. Aplikasi siap pakai yang diakses melalui internet. Contoh: Google Docs, Microsoft 365, dan Canva.

04 · Perkembangan terkini

Tren cloud computing saat ini

Salah satu tren penting adalah serverless computing, yaitu pendekatan menjalankan kode tanpa perlu mengelola server secara langsung.

Serverless Computing

Penyedia cloud menangani pengelolaan infrastruktur, sementara pengembang berfokus pada kode dan fungsi aplikasi. Server tetap digunakan di belakang layar, tetapi pengelolaannya banyak ditangani penyedia.

Keunggulannya antara lain mengurangi pekerjaan pengelolaan server, dapat menyesuaikan kapasitas secara otomatis, dan pada layanan tertentu biaya dihitung berdasarkan jumlah eksekusi atau pemakaian.

Contoh penerapan

Sebuah toko online ingin mengirim email konfirmasi setiap kali pelanggan membuat pesanan. Fungsi serverless dapat berjalan saat pesanan baru tercatat, lalu berhenti ketika tugas selesai. Pengembang tidak harus mengelola server khusus untuk fungsi tersebut.

🔀

Hybrid dan multicloud

Organisasi menggabungkan infrastruktur sendiri dengan cloud publik, atau menggunakan beberapa penyedia cloud sesuai kebutuhan.

🤖

AI dan cloud

Cloud menyediakan komputasi dan layanan terkelola untuk melatih, menjalankan, serta mengintegrasikan model kecerdasan buatan.

🛡️

Keamanan dan efisiensi

Perhatian terhadap perlindungan data, kontrol akses, pemantauan biaya, dan penggunaan sumber daya yang lebih efisien terus meningkat.

05 · Penerapan

Manfaat dan hal yang perlu diperhatikan

⚡

Manfaat

Mengurangi kebutuhan membeli perangkat keras sendiri, mempercepat penyediaan layanan, memudahkan kolaborasi, dan mendukung akses dari berbagai lokasi.

🔒

Keamanan data

Gunakan kata sandi kuat, autentikasi multifaktor, pengaturan izin yang tepat, serta pencadangan data secara berkala.

📶

Keterbatasan

Layanan dapat bergantung pada koneksi internet, biaya dapat meningkat jika tidak dipantau, dan pengguna perlu memahami lokasi serta aturan pengelolaan data.

06 · Contoh sederhana

Bagaimana cloud digunakan?

Misalnya, mahasiswa mengerjakan tugas kelompok menggunakan dokumen online.

1

Buka aplikasi

Mahasiswa membuka aplikasi dokumen melalui browser.

2

Data disimpan

Dokumen disimpan di infrastruktur penyedia layanan cloud.

3

Kolaborasi

Anggota kelompok dapat mengedit dokumen sesuai izin.

4

Akses kembali

Dokumen dapat dibuka kembali dari perangkat lain melalui akun pengguna.

Kesimpulan: Cloud computing memungkinkan sumber daya komputasi digunakan melalui internet secara fleksibel. Perkembangannya berawal dari gagasan berbagi sumber daya komputer dan kini mendukung berbagai layanan digital. Pengguna tetap perlu memperhatikan keamanan, privasi, ketergantungan internet, dan pengendalian biaya.
